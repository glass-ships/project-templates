### Components

There are several options of third party components that can be used in a Vue application.  
Here are some of the most popular ones, some of which are "headless" (meaning they are not styled and can be styled to fit the project's design) and some are styled components:

- [Oruga](https://oruga.io/)
- [TanStack Table](https://tanstack.com/table/v8)
- [Headless UI](https://headlessui.com/)
- [Radix Vue](https://www.radix-vue.com/)
- [Zag Js](https://zagjs.com/)
