# Frontend Templating

Much of the frontend templating is takin from my experience working with (or was written by) [Vince Rubinetti](vincerubinetti.com) for the [Monarch Initiative](https://monarchinitiative.org/).

```
frontend/
├── global              # global styles and icons
├── react_project/
│   ├── components/     # reusable components
│   ├── composables/    # composable functions
├── vue_project/
│   ├── components/     # reusable components
│   ├── composables/    # composable functions

```

### Components

There are several options of third party components that can be used in the frontend. Here are some of the most popular ones,  
some of which are "headless" (meaning they are not styled and can be styled to fit the project's design) and some are styled components:

#### React

- [react-aria](https://react-spectrum.adobe.com/react-aria/index.html)

#### Vue 3

- [Oruga](https://oruga.io/)
- [TanStack Table](https://tanstack.com/table/v8)
- [Headless UI](https://headlessui.com/)
- [Radix Vue](https://www.radix-vue.com/)
- [Zag Js](https://zagjs.com/)
