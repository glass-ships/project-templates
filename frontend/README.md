# React/TypeScript Project

This is a template for a React TypeScript project intended for use with Vite and Bun.  
Next.js can also be used, but will require some changes to `package.json` and other configurations.

It is built using:

- React: A popular JavaScript library for building user interfaces.
- TypeScript: A typed superset of JavaScript that compiles to plain JavaScript.
- Vite: A fast build tool that provides a development server and optimized production builds.
- biome.js: A JavaScript and TypeScript linter and formatter.

And contains:

- A basic folder structure for organizing your components, hooks, and styles.
- A sample `App` component to demonstrate how to use React with TypeScript.
- Several custom hooks, utilities, and UI components to help you build your application.

## Dependencies

- [bun](https://bun.sh/)
